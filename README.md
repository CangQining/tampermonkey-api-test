# API 接口调试助手

豆包写的，有问题让她改。
1.可以自动记录请求，不需要按F12再开启记录。
2.如果返回值有list可以直接预览。
3.请求数据持久化，刷新 / 关闭页面都不会丢
一个轻量的浏览器端 API 接口调试工具，无需后端服务，安装后即可在浏览器里调试网页的接口请求，支持请求重发、响应调试、数据导出等功能。

## ✨ 功能特性

- 🚀 **自动拦截请求**：自动记录网页的 XHR 和 Fetch 请求，无需手动配置
- 🔒 **网站数据隔离**：不同网站的请求数据完全隔离，不会互相混淆，解决了传统工具全局存储的问题
- 🔄 **请求重发**：选中请求后可以修改参数重新发送，快速调试接口
- 📝 **自定义请求**：支持直接发送自定义的 API 请求，无需额外工具
- 📊 **多模式响应展示**：
  - JSON 格式化：可折叠的 JSON 树，方便查看复杂的响应数据
  - 表格展示：将数组数据转为表格，更直观的查看列表数据
  - 原始数据：查看原始的响应文本
- 🎛️ **表格自定义字段**：表格模式下可以自定义勾选需要展示的字段，隐藏不需要的内容
- ⚡ **实时数据路径**：输入数据路径自动定位到对应的数组数据，输入即生效，无需点击应用
- 📐 **面板位置自定义**：
  - 底部模式：面板在页面底部，可拖动调整高度
  - 右侧模式：面板在页面右侧，可拖动调整宽度
- 🔍 **请求筛选**：支持按接口名称、参数搜索，也可以按请求方法筛选
- 📦 **导入导出**：支持请求数据的导入导出，方便备份和分享调试数据
- 🔢 **请求计数**：浮动按钮自动显示当前网站的请求数量，超过 99 个自动显示 `99+`
- ⌨️ **快捷键支持**：`Ctrl+Shift+A` 快速打开/关闭调试面板
- 🧹 **自动清理**：自动限制最大保存请求数，避免数据过多导致卡顿

### 1. 安装油猴插件
首先需要安装油猴（Tampermonkey）浏览器插件，支持 Chrome、Firefox、Edge 等主流浏览器：
- [官网](https://www.tampermonkey.net/)

### 2. 安装脚本
安装完油猴后，你可以：
- 下载/新建脚本把代码复制进去

## 📖 使用方法

1. 安装完成后，打开任意网页，你会在页面**右侧中间**看到一个浮动按钮：`🔧 API (N)`，N 就是当前网站的请求数量
2. 点击这个按钮，就可以打开调试面板
3. 面板会自动记录当前页面的所有 API 请求，点击任意请求就可以查看详情
4. 在响应标签页，你可以切换不同的展示模式，调试响应数据
5. 在重发标签页，你可以修改请求参数，然后重新发送请求
6. 在自定义请求标签页，你可以直接发送自定义的 API 请求

## 🎯 功能说明

### 面板位置切换
你可以点击面板顶部的「设置」按钮，切换面板的位置：
- 底部模式：面板在页面底部，适合宽屏，可拖动顶部的分隔条调整高度
- 右侧模式：面板在页面右侧，适合高屏，可拖动左侧的分隔条调整宽度

### 表格自定义字段
当你切换到表格展示模式后，点击「自定义字段」按钮，就可以勾选你需要展示的字段，勾选后表格会自动更新，选择新请求时会自动重置为全部展示。

### 表格数据路径
如果你的响应数据是嵌套的，比如 `{ code: 0, data: { list: [...] } }`，你可以在数据路径输入框里输入 `data.list`，表格就会自动定位到这个数组，输入的时候表格会实时更新。

### 搜索和筛选
你可以在顶部的搜索框里输入关键词，快速搜索接口名称、请求参数或者响应数据，也可以通过方法筛选下拉框，只看特定方法的请求。
